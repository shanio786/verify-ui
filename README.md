# VERIFY-AU

Static SPA with a tiny zero-dependency Node static server.

## Deploy

```bash
git clone -b deploy https://github.com/shanio786/verify-ui.git verify-au
cd verify-au
node server.js   # serves on PORT env var (default 8080)
```

For aaPanel Node Project: set Run opt = `node server.js` (or use the default `npm start`).
